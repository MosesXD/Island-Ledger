# Island Ledger — Personal Money Dashboard

A beginner-friendly money tracker prototype built with plain HTML, CSS, and JavaScript. It uses TTD formatting and browser `localStorage` to remember entries on the same browser.

## Features in this starter

- Add income and expense transactions
- Choose a category and date
- See income, expenses, and net balance totals
- View a basic spending-by-category breakdown
- Delete one transaction or clear local demo data
- Responsive layout for phone and desktop
- No external libraries or build step required

## Run it

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Add a few clearly fictional test transactions.
4. Refresh the page to confirm local demo data persists.

## Files

- `index.html` — page structure and form
- `style.css` — visual design and responsive layout
- `app.js` — calculations, rendering, and browser storage

## Current limitations

This is a learning demo, not a secure finance app. It does not connect to banks, sync across devices, authenticate users, encrypt entries, or provide financial advice. Data is stored in this browser and can be lost if site data is cleared. Do not enter sensitive financial information.
